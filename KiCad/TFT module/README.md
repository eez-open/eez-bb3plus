### BB3+ 5" DVID TFT Touchscreeen display (800 x 480) 

* 4 user programmable keys
* 5" TFT LCD capacitive touchscreen
* HDMI® compatible digital video input
* 5V DC input
* Optional resistive touchscreen controller
* Optional EDID EEPROM
